## ⚠️ Critical Configuration Points

### 1. Cloudflare DNS Setup
- **File**: MIGRATION_GUIDE.md → Cloudflare DNS Configuration
- **Script**: None (manual setup in Cloudflare Console)
- **Critical**: Must be "DNS only" (⬜ Gray Cloud), NOT proxied 🟠

### 2. Oracle Cloud Firewall
- **File**: MIGRATION_GUIDE.md → Oracle Cloud Setup → Configure Firewall
- **Ports Needed**:
  - TCP 80 (HTTP)
  - TCP 443 (HTTPS)
  - UDP 1194 (OpenVPN)
  - TCP 853 (DNS over TLS)

### 3. Certificate Migration
- **File**: MIGRATION_GUIDE.md → Certificate Migration
- **Script**: setup-openvpn.sh (initializes after certs copied)
- **Required Files**:
  - ca.crt
  - server.crt
  - server.key
  - dh.pem
  - ta.key

### 4. Split Tunneling Configuration
- **File**: MIGRATION_GUIDE.md → Split Tunneling with PAC
- **Client Config**: Generated by generate-client.sh
- **Advanced**: Edit proxy.pac for browser-level routing

## 🔧 Quick Command Reference

### Deployment Commands
```bash
# Initialize OpenVPN
bash setup-openvpn.sh

# Update Traefik for UDP
docker-compose -f traefik-docker-compose.yml up -d

# Deploy OpenVPN
docker-compose -f docker-compose-openvpn.yml up -d
```

### Client Management Commands
```bash
# Generate new client
./generate-client.sh alice_ipad vpn.example.com 1194

# Renew certificate
./renew-client-cert.sh alice_ipad vpn.example.com 1194

# Revoke access
./revoke-client.sh alice_ipad

# List all clients
./list-clients.sh

# Backup
./backup-openvpn.sh
```

### Monitoring Commands
```bash
# View logs
docker logs openvpn
docker logs traefik

# Monitor resources
docker stats openvpn traefik

# Check connected clients
docker exec openvpn tail -f /etc/openvpn/openvpn-status.log

# Test UDP port
nc -u -zv vpn.yourdomain.com 1194

# Check DNS
dig vpn.yourdomain.com
```
